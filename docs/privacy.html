Política de privacidad

Esta integración utiliza rclone y OAuth 2.0 para acceder a archivos de Google Drive, exclusivamente mediante autorización del propietario de la cuenta.

El acceso permite listar, leer, crear, modificar y eliminar archivos para ejecutar operaciones de sincronización.

Las credenciales se almacenan localmente. El propietario no opera servidores intermediarios ni comercializa los datos accedidos mediante esta integración.

El acceso puede revocarse desde la configuración de seguridad de Google.
